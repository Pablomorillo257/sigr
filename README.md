# Sistema Integral de Gestión de Restaurante (SIGR)

Este repositorio contiene la arquitectura inicial y los artefactos base estables que componen la Línea Base del proyecto SIGR. Su finalidad es servir como punto cero para el control de cambios de la gestión operativa del restaurante.

## Datos de la Línea Base de Configuración
- **Repositorio Oficial:** https://github.com/Pablomorillo257/sigr
- **Rama Principal:** main
- **Commit ID de la Línea Base:** f6bae7e
- **Fecha de Establecimiento:** 31 de Octubre de 2026

## Estructura de Directorios del Proyecto
- `/autenticación`: Componentes lógicos para la autenticación de usuarios.
- `/menu`: Módulos asociados al CRUD de platos y categorías del menú digital.
- `/orders`: Tablero de registro y seguimiento de pedidos en tiempo real.
- `/reservations`: Lógica del calendario de reservas de mesas.
- `/billing`: Procesamiento de cierres de caja y facturación diaria.
